Configurações

Conecte o backend para ativar as respostas da IA.

Use a URL do Worker que você controla, sem adicionar /api/chat. O endereço fica salvo apenas neste navegador.

O histórico desta versão fica no armazenamento local do navegador. As mensagens enviadas ao chat são encaminhadas ao Worker configurado. Não coloque senhas, dados pessoais ou informações privadas nas conversas. A chave da API deve ficar como Secret no Cloudflare Worker, nunca nesta página.

Versão 1.0 · Interface experimental. AI Chat, Code Assistant e AI Writer usam o mesmo serviço de chat conectado ao Worker.
